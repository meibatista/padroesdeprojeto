**Padrão Comportamental = State** : esse padrão permite que um objeto altere seu comportamento quando seu estado interno muda. O objeto parecerá ter mudado de classe. Na sua implementação, em vez de usar múltiplos blocos `if` ou `switch` para tratar o comportamento baseado no estado atual, o contexto delega o trabalho para um objeto de estado específico. No exemplo, `Pedido` delega o processamento para a interface `EstadoPedido`, e as classes concretas (`PedidoPendente`, `PedidoPago`, `PedidoEnviado`) implementam as regras de transição específicas, alterando o próximo estado do pedido assim que uma ação é realizada.
